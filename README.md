# DashVision

**DashVision** — это веб-приложение, разработанное в рамках Выпускной Квалификационной Работы по теме:  
**"Разработка веб-приложения «Дашборд» (интерактивная аналитическая панель)"**.

Приложение обеспечивает мониторинг метрик различных промышленных устройств на заводах в удобной визуальной форме.

## 🔧 Что необходимо для запуска

Для запуска приложения вам понадобятся только:

- [Docker](https://www.docker.com/)
- [Git](https://git-scm.com/)

Все остальные зависимости будут автоматически установлены через Docker.

## 📥 Установка и запуск

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/MrRemohovsky/Dash
cd Dash
```

2. **Запустите сборку и приложение:**
```bash
docker-compose up --build -d
```

> ⏳ Примерное время сборки — около 2 минут (зависит от скорости интернета и мощности компьютера).

3. **Перейдите в браузере по адресу:**
```
http://127.0.0.1:5000
```

Готово! Вы в приложении.

## 🧹 Остановка и удаление контейнеров

Если нужно остановить приложение и удалить все контейнеры, тома и "осиротевшие" ресурсы, используйте:

```bash
docker-compose down --volumes --remove-orphans
```
